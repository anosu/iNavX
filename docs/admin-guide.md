# 后台与收录申请使用指南

后台入口为 `/admin`，访客收录申请入口为 `/submit`。运行、初始化凭据、密码重置与恢复命令见[部署说明](deployment.md)。

## 公共内容与个人收藏

后台管理公共目录。站点、分类、设置保存后即时生效，已打开的首页重新加载后更新。首页“添加”和书签导入保存到访客自己的浏览器；个人收藏不会自动成为公共条目。相同 URL 优先展示个人版本。

个人数据使用首页“导出”菜单生成个人备份；公共内容与申请历史使用后台迁移包。更换浏览器或前台域名之前，要分别备份这些数据。

旧浏览器数据逐条校验，损坏或不安全的站点地址不显示；只打开首页不会覆盖原始存储。个人备份恢复若因存储空间不足失败，会回滚已写入的个人数据。已有损坏数据可能使个人备份导出校验失败，需要先保留原始数据再修正。

首页引擎设置可拖拽、点击上下箭头或在行内使用 `Alt + ↑/↓` 调整顺序，`Escape` 关闭并返回设置按钮。管理员移除最后一个已选择的引擎后，仍有公共可用引擎时会自动保留一个；管理员关闭全部引擎时不提供外部搜索。

首页卡片显示标签，超过两个时可展开查看。点击标签进行精确匹配，可与分类和关键词组合筛选；点击结果上方筛选标签的 × 取消。标签仍参与首页与命令面板的关键词搜索。个人收藏的标签也适用，但只保存在当前浏览器。

个人添加、后台编辑、匿名提交和审核共用标签输入：已添加的标签以标签块显示，按 Enter 添加，逗号作为标签内容保留，例如 `C, C++` 是一个标签。点标签上的 × 删除指定标签；空输入框第一次按 Backspace 选中最后一项，第二次按才删除，长按不会连续删除。输入、其他按键或离开输入框会取消选中。自动修剪首尾空格并去重，最多 30 个，每个最多 100 个字符；保存包含输入框中最后未按 Enter 的标签。标签内部空格和大小写保留，点击筛选按完整标签精确匹配。

首页和后台编辑弹窗没有修改时，点击背景即可关闭；有未保存内容时，背景点击不关闭。拖选文字到弹窗外或滑动背景不会触发关闭。首页个人站点表单有未保存内容时，点击 ×、取消或按 Esc 会提示继续编辑或放弃修改，未确认的标签和新分类输入也受保护。刷新或关闭页面时浏览器会提醒；草稿不跨刷新保留。命令面板仍可点击背景关闭。保存或提交期间禁止重复提交、关闭编辑弹窗或通过站内跳转离开表单，失败后保留输入。

## 管理站点

“站点管理”支持名称、URL、描述和标签搜索，以及分类筛选。每页 25 条；桌面使用表格，手机使用带操作按钮的卡片。编辑时可以调整名称、分类、地址、图标、描述、标签、排序和置顶。

数字越小越靠前。删除操作先移入回收站；可以修改地址后恢复，也可以在回收站永久删除。永久删除无法撤销，关联申请会显示站点已删除，申请本身也可删除。恢复时检查已收录 URL 冲突。

后台地址保留当前分区，刷新后仍停留在该分区。表单有修改时，切换页面和退出会提醒；关闭编辑或审核对话框时也可以选择继续编辑。长表单只滚动内容区，标题、关闭按钮和底部操作始终可见。保存失败会在对话框内提示并保留填写内容，修正后再次提交。

## 管理分类

“分类管理”中点击“新增分类”或某行的“编辑”，会在当前位置打开表单，自动聚焦分类名称；关闭后保留列表浏览位置。名称与排序保存后即时生效，新增分类默认排在现有分类之后。

删除前显示关联站点总数（含回收站）。可以迁移到其他分类，或连同所属站点一起永久删除；空分类可直接删除，最后一个分类也可以删除。没有分类时先新增分类，再录入或批准站点。

## 图片与辅助服务

“站点设置 → 图片与辅助服务”提供两个独立开关：

- 允许加载远程图片：默认关闭；关闭时只加载与当前前台同源的图片，其他站点图标显示文字。控制站点图标、搜索引擎图标、Logo 和个人表单预览，不删除原地址。
- 启用链接标题与描述获取：默认关闭；启用并填写元数据代理模板后，添加个人收藏会请求代理并预填名称/描述。模板留空时仍不请求。目标网址会发送给代理，使用可信或自建服务，并确保浏览器可以访问它。

默认站点图标模板使用 `{domain}`，适用于没有单独图标地址的站点；留空显示文字图标。元数据代理模板使用 `{url}` 并返回目标页面的 HTML。两种模板都支持站内路径或 HTTP / HTTPS 地址，没有隐藏的备用服务。搜索地址继续要求 HTTP / HTTPS 和 `{q}`，在“搜索引擎”分区调整。

Logo、站点和引擎图片可以使用 `/icons/example.svg` 等站内路径，也可在开启远程图片后使用外部地址。分离前台中的站内路径相对于前台域名；后端域名上的图片属于远程图片。首版不提供文件上传，可将图片放到 `public/` 后重新构建，或由同源反向代理提供静态资源。

SVG 推荐使用包含 `xmlns="http://www.w3.org/2000/svg"` 的标准文件。图片加载失败时，前端会尝试修补缺少该命名空间的 SVG；外部来源需允许跨域读取，文件不得超过 256 KiB。其他无效或不可访问的图片仍显示默认图标。

旧实例与旧迁移包缺少开关时默认关闭，原地址仍保留；需要继续加载时显式开启。新实例的种子站点和默认引擎没有固定代理地址。验证码仍通过服务器环境变量按需配置，步骤见部署说明。站内 `/about` 是访客使用指南，不承担后台运维文档的职责。

## 审核收录申请

1. 访客填写名称、网站地址、选填描述、建议分类与建议标签，提交后看到“申请已接收”。申请默认不公开。
2. 管理员打开“收录申请”，默认显示待审核列表；可以搜索、筛选状态或刷新查看新申请。
3. 打开“审核申请”，原始提交信息保留在上方；选择处理方式。
4. 批准时编辑公开名称、地址、分类、图标、描述与标签，标签初始值来自申请。点击“批准并公开”，站点创建与申请状态更新在同一事务内完成。原申请建议标签保留在详情中，公开标签可独立调整。
5. 对已收录内容选择“标记为重复申请”，并关联有效的公共站点；不符合收录范围时选择“拒绝申请”。

审核备注只对管理员可见。所有状态的申请均可永久删除，内容与审核结果一起删除，已收录站点不受影响。已处理申请可查看详情，不能改回待审核。重复批准不会再创建站点；URL 冲突或其他写入失败时，申请保持待审核，可修正后重新处理。申请人目前无法查询状态，也不会收到邮件通知。

关闭“站点设置 → 接收匿名收录申请”会停止新提交，不删除历史申请，也不影响处理历史申请。建议在管理员初始化后核对开关和防滥用配置。

## 备份与恢复

“备份与迁移”可生成、下载或永久删除原生数据库备份，或导出版本 4 迁移包；二者都包含申请、建议标签与审核记录。版本 1～3 仍可导入，旧申请缺少标签时视为空；含申请标签的包只能使用版本 4，旧程序不能读取它。迁移包排除管理员凭据和会话。服务器备份不包含访客个人收藏。旧备份保留生成时的数据，需要时分别删除；自动备份间隔设为 0 可关闭自动生成。

导入先预览，再合并或覆盖。解析期间有进度提示；摘要显示文件名，切换文件后以最新选择为准，错误显示在导入区。合并保留当前配置，同 ID 的申请不覆盖现有审核结果；覆盖会替换公共内容、配置与申请历史。旧版本 1 迁移包不含申请，覆盖它会清空当前申请历史。确认覆盖前请检查文件名与摘要；执行前系统会自动备份。

原生数据库恢复需要停站并使用 CLI，步骤见[原生恢复](deployment.md#原生-sqlite-恢复)。图片和远程图标使用 URL，不复制到迁移包。
